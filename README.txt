MEDCONTROL PWA

Esta es una versión web-app para iPhone.

IMPORTANTE:
- La app viene precargada con Augmentine 875/125 mg cada 8 h, primera toma = momento de instalación/configuración.
- Ibuprofeno 600 mg cada 8 h, primera toma = aproximadamente una hora antes de la configuración.
- Para que las notificaciones web funcionen de forma fiable en iPhone, la app debe servirse desde una web segura (HTTPS) y añadirse a la pantalla de inicio. El archivo HTML por sí solo puede probarse localmente, pero no ofrece todas las capacidades PWA.

La app guarda el registro en el almacenamiento local del navegador.
